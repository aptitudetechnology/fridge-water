# color/

These two files are redirects, kept so that earlier links to the colour edition keep working:

- `color/` goes to `/?colour=1`
- `color/fridge-water` goes to `/fridge-water?colour=1`

The colour edition is now a **switch on the main site**: the "Colour" checkbox beside "Sound effects" on the animation page. It remembers your choice, and `?colour=1` (or `?colour=0`) in a link sets it.

The palette and the colour rules live in `fridge-water.html` (search for `COLOUR`, `MAC16`, `FAMILY` and `LC`). The colour edition uses the classic Macintosh II 16-colour system palette, approximately, with a colour family for each act and one colour for each evidence label (always printed with its name).
