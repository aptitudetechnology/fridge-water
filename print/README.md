# print/

Sample printouts made by the **Print** button, so you can judge the layout without clicking through the site. They were generated by loading the page, building the print view for one section with the default frame choices, and printing to PDF with Chromium. A browser's own Print dialog gives the same page.

## How to try it on the site

1. Click **Print** at the top right of any section. A chooser opens with a thumbnail for every narration line of every picture in that section. Each frame is the picture as it looks when the narrator finishes that line.
2. Tick the frames you want (the last frame of each picture is pre-ticked), and choose whether to include the dialogue, the references, and colour.
3. Click **Print**. The browser's print dialog opens on a clean page: the title, the frames with a note of which line each illustrates, the numbered dialogue, the references and notes, and a footer with the address of the section, the print date and the licence.

A link such as `https://fridge-water.ownhealth.bio/fridge-water?print=s8` opens the chooser for scene 8 straight away.

## What's in the references

Each citation comes from the PubMed record. Where the project has only read a study at the title or abstract level, or has only seen a summary, the section's note says so. Sections that are imagined scenes or arguments say that no study is cited, instead of citing something loosely related.

## Ideas for testing

- Print one section in black and white and in colour, and compare the ink.
- Print a section with several frames chosen, and check the captions match the dialogue.
- Open the page in dark mode and print: the printed page should still be black on white.
- Try "Save as PDF" in your browser's print dialog.

This is a desktop page. The site isn't designed for phones, so the Print button isn't tuned for them.
